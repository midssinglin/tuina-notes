# 任務：把一本推拿／整復參考書整理成知識庫補充條目，並找出與課程理論的衝突

你在幫一位推拿整復課程的學員，把參考書整理進他的學習網站「推拿整復手札」的知識庫（繁體中文、台灣用語）。

## 輸入
- 書的 OCR 文字：`/home/claude/ocr/{BOOK}.txt`（掃描書的自動辨識，錯字多；每頁以 `=== [PDF 第 N 頁] ===` 分隔）。OCR 看不懂的關鍵頁（圖表、表格），可以用 `pdftoppm -r 110 -f N -l N "/mnt/user-data/uploads/補充資料/{BOOK}.pdf" /home/claude/ocr/pg/{SLUG}` 轉成圖片後用 Read 看（每頁很耗 token，只看真正需要的頁，全書最多 25 頁）。
- 課程既有資料：`/home/claude/ocr/course_ref.md`（網站目前的知識條目、評估模式、經筋、經絡、肌肉 id、穴位 id、部位 id、分類）。

## 版權規則（一定要遵守）
這是出版書籍，網站與 GitHub 都是公開的：
- **用你自己的話重寫**重點；不要逐字抄錄句子或段落（專有名詞、穴名、肌肉名、短的術語可以用）。
- 不要複製書中的表格原文或圖片；可以描述「我們重新畫的示意圖」要畫什麼。
- 每則條目標出處：書名＋頁碼（盡量用書上印的頁碼；看不出來就寫「PDF 第 N 頁」）。

## 要求
- entries 12–25 則，挑**對評估與手法最有用、而課程資料沒有或講得比較少**的內容；與課程重複的不用再寫，除非書有明顯補充。
- figs 3–6 張，挑最需要圖才能懂的內容（例如經筋循行、手法步驟、評估姿勢、力學示意）。
- conflicts 要**仔細逐一比對**課程的核心理論：骨盆三個角度（A/P、EX/IN、耳狀面外展內收）與對應肌肉、薦椎、長短腳判讀、經筋循行與病候、經絡穴位定位與主治、肌肉作用、評估順序、安全禁忌。只列真正有出入或值得注意的地方；沒有衝突就說明「一致」的重點（type 用「補充」）。不要捏造：每一條都要有頁碼。
- OCR 有錯字時，依上下文判斷，不確定就略過。
- 最後回覆給我：產出檔路徑、entries/figs/conflicts 數量、以及「最重要的 5 個衝突或差異」一行一則（含頁碼）。不要在回覆貼整份 JSON。
